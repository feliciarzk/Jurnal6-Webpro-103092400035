# Jawaban Teori WEBPRO Modul 6

## 1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya!
JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman website menjadi interaktif dan dinamis. JavaScript dapat merespons tindakan pengguna, memvalidasi input, memanipulasi elemen HTML, mengubah tampilan halaman, serta memproses data. Contohnya, JavaScript dapat digunakan untuk menampilkan pesan, meminta input nama melalui `prompt()`, dan mengubah isi elemen website secara otomatis.

## 2. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
jQuery adalah library JavaScript yang menyediakan berbagai fungsi untuk mempermudah pengembangan website. jQuery menyederhanakan penulisan kode untuk memilih elemen HTML, menangani event, mengubah CSS, menyembunyikan atau menampilkan elemen, serta melakukan manipulasi DOM. Contohnya, jQuery dapat digunakan untuk mengubah warna sebuah kotak ketika tombol ditekan dengan kode yang lebih ringkas.

## 3. Jelaskan perbedaan JavaScript dan jQuery!
JavaScript merupakan bahasa pemrograman, sedangkan jQuery merupakan library yang dibuat menggunakan JavaScript. JavaScript dapat digunakan secara langsung tanpa library tambahan, sementara jQuery perlu dimuat ke halaman website sebelum fungsi-fungsinya digunakan. Perbedaan lainnya terletak pada penulisan kode. JavaScript memiliki sintaks bawaan untuk memanipulasi elemen HTML dan menangani event, sedangkan jQuery menyediakan sintaks yang lebih ringkas untuk melakukan tugas-tugas tersebut. Meskipun demikian, keduanya dapat digunakan untuk membuat website interaktif, dan jQuery sebenarnya tetap berjalan menggunakan JavaScript.
